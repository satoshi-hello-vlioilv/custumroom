# custumroom — ルームプランナー 3D

ブラウザで動く 3D ルームプランニングアプリです。ビルド工程は不要で、依存は CDN から読み込みます。コードは責務ごとに ES モジュールへ分割されており、モデルの追加・編集がしやすい構成になっています。

## デモ

ES モジュール（`js/` 配下）を使用しているため、`index.html` を `file://` で直接開くとブラウザの CORS 制限で読み込みに失敗します。**ローカルサーバー経由で開いてください。**

```bash
python3 -m http.server 8080
# → http://localhost:8080/ をブラウザで開く
```

## 主な機能

### 3D ビュー
- **Three.js r160** による PBR レンダリング（物理ベースのマテリアル）
- スマートカットアウェイモード：外壁を自動で透過表示
- 軌道カメラ操作（ドラッグ・ピンチで回転・ズーム）

### 2D フロアプランエディタ
- グリッドスナップ（0.5m 単位）で壁と床セルが完全一致
- 壁の描画・削除、床の塗りつぶし
- 開口部（ドア・窓・ガラス戸）の配置
- 3D ビューとリアルタイム同期

### 壁タイプ
| タイプ | 説明 |
|--------|------|
| 普通の壁 | 不透明な壁 |
| 窓付き壁 | 腰高窓（サッシ＋ガラスペイン）付き |
| ガラス壁 | 全面透明ガラス（アルミフレーム付き）。開口（ガラスドア／出入口）にも対応し、間仕切りをガラス化できる（ABWオフィスのプロジェクトルーム・集中ブースに採用）。**壁を「不透過」表示にしてもガラス壁・窓ガラスは素材がガラスのため常に透過（最低30%）を保つ** |

| カテゴリ | アイテム例 |
|----------|-----------|

| インテリア | フロアランプ、観葉植物、テレビ、壁掛けテレビ、ラグ |
| オフィス／店舗 | 受付カウンター、会議テーブル、ホワイトボード、**連続デスク（隙間なく並ぶベンチデスク）**、**ゴンドラ什器（両面・端を突き合わせる売場棚）**、レジ、ショーケース冷蔵庫 |

### プリセット
- 住宅・オフィス・店舗・工場・特殊（博物館・実験室・教室など）の20種類。一覧では家具の配置まで描いた平面図で比べられる

### その他
- 家具の色変更・回転・削除
- 家具の積み重ね（植物、テレビなど）
- アンドゥ / リドゥ（Ctrl+Z / Ctrl+Y）
- レイアウトの保存 / 読み込み（JSON 形式、v5 フォーマット）
- 3D ビュー左上の「？」で操作方法、配置中・床ペイント中は画面下にその場で使える操作をヒント表示

## 使い方

### 画面構成（v2.0.0〜）

| 場所 | 内容 |
|------|------|
| ツールバー | 「プリセット」「間取り編集」／元に戻す・やり直し／読み込み・保存・画像保存・新規スタート／自動保存の状態 |
| 左パネル「家具」タブ | 左の縦列でカテゴリを選び、3Dサムネイル付きの一覧から家具をクリック → 3Dビューをクリックして配置。「すべて」ではカテゴリ見出しで区切って表示 |
| 左パネル「内装」タブ | 壁紙・床材の変更、床ペイントのオン/オフ、部屋の外形と家具の点数 |
| 左パネル「メモ」タブ | プリセットの配置メモ（メモがあるとタブに点が付く） |
| 左パネル下部（家具を選択したとき） | 選択中の家具の詳細: 周囲との間隔（ひとことの判定＋上から見た図）、カラー（10色＋「ほか○色」）、位置、実寸・出典。カタログを見ながら編集できる |
| 3D ビュー左上 | 壁の見せ方（全表示／手前カット／手前半透明／全半透明）、グリッド、真上から見る、操作方法（？） |
| 選択した家具の真上 | ミニツールバー: 左右回転・色・複製・削除 |
| 3D ビュー右下・左下 | ズーム／視点リセット、スナップ幅 |

### 基本操作

| 操作 | 説明 |
|------|------|
| 左ドラッグ | カメラ回転 |
| 右ドラッグ / 中ドラッグ | カメラパン |
| スクロール | ズーム |
| 家具カタログにマウスオーバー | 3Dプレビュー（小窓でモデルを回転表示し、メニュー内で選びやすく） |
| 家具クリック | 選択（左パネル下部に詳細、家具の上にミニツールバー） |
| 家具ドラッグ / ダブルクリック | 移動 / 90°回転 |

### 間取り編集

ツールバーの「間取り編集」で 2D エディタを開きます（ほぼ全画面）。3D にリアルタイムで反映されます。

| 場所 | 内容 |
|------|------|
| ツールバー | 床を描く <kbd>F</kbd>／床を消す <kbd>E</kbd>／範囲を均一化 <kbd>U</kbd>／壁を引く <kbd>W</kbd>／開口を追加 <kbd>D</kbd>／壁を消す <kbd>X</kbd>、右端の「部屋」で幅・奥行・長方形に戻す・全消去 |
| 設定バー | 選んだツールの説明と、そのツールの設定だけ（床材は色見本、壁タイプは図面と同じ線の見本、開口タイプ、ブラシの太さ） |
| 図面 | 全体寸法、ズーム／全体表示ボタン、壁・床にマウスを乗せると種類・長さを表示。ホイールでズーム、右ドラッグで移動 |
| 開口の編集 | 「開口を追加」で既存の開口をクリックすると右上に編集パネル（種類・幅・吊り元・開く向き・削除） |

### プリセット

ツールバーの「プリセット」で間取りの一覧を開きます。カードをクリックすると右に大きな平面図と説明が出て、「この間取りを読み込む」で読み込みます（ダブルクリックでも読み込めます）。
「空の部屋」では、約6畳〜倉庫/工場の大きさを選ぶか、幅×奥行を入力して家具のない部屋を作れます。

### 床ペイントモード

左パネル「内装」タブの「床ペイント」をオンにし、床材を選んで 3D ビューを左ドラッグで塗り、右ドラッグで消します（Esc で終了）。

### 保存・読み込み

- 「保存」ボタン：JSON ファイルをダウンロード
- 「読み込み」ボタン：保存した JSON を読み込む

## ファイル構成

責務ごとにファイルを分割しています。新しい家具・機械モデルを追加するときは、
**該当する `js/builders/*.js` に `buildXxx()` を追加 → `js/catalog.js` の
`FURNITURE_DEFS` に 1 行登録** するだけで済みます（必要なら `js/builders/<file>.js`
の `export { ... }` にも名前を追加）。

```
custumroom/
├── index.html              # HTML マークアップのみ（importmap + js/app.js を読み込む）
├── css/
│   └── style.css           # 全スタイル
└── js/
    ├── app.js              # アプリ状態・部屋/壁・配置・選択・UI・2D エディタ・保存・起動
    ├── catalog.js          # FURNITURE_DEFS（家具カタログ定義。各 builder を参照）
    ├── presets.js          # プリセット（部屋レイアウト）定義
    ├── core/
    │   ├── scene.js        # renderer / scene / camera / ライト / 環境マップ
    │   ├── textures.js     # 手続き的テクスチャ生成・床/壁タイプ定義
    │   ├── helpers.js      # 幾何ヘルパー（mat/box/cyl/cylAt 等）・定数・COLORS
    │   └── util.js         # 純粋ユーティリティ（clamp / shade）
    └── builders/           # ★モデル生成関数（責務＝用途ごとに分割）
        ├── furniture.js    # 住宅家具・照明・装飾
        ├── household.js    # キッチン・水回り・家電・収納
        ├── office.js       # オフィス・店舗・展示什器
        ├── plants.js       # 観葉植物シリーズ
        ├── industrial.js   # 大型工場機械・搬送・物流（CNC/ロボット/プレス 等）
        ├── lab.js          # 実験室・工房・試験/工作機器
        └── instruments.js  # 分析機器（HPLC・分光光度計 等）
```

### モジュール依存関係

```
util ← textures ← helpers ← builders/* ← catalog ← presets ← app
scene ← textures              scene ← app
```

すべて純粋な ES モジュールで、ビルドツールは不要です。
